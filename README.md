# FreshCart E-commerce

An e-commerce web app built with React, Vite, Tailwind CSS and React Router.

## Live Demo
https://final-app-mu-five.vercel.app

## Features
- Register, Login, Forgot Password, Change Password
- Homepage with slider, categories, offers and featured products
- Products, Product Details, Brands and Categories (with filtering)
- Cart: display, add, remove, update quantity
- Wishlist: display, add, remove
- Checkout: cash and online payment
- Orders page

## Run locally
npm install
npm run dev
